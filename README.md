# React Hospitality Assignment

A hospitality-focused frontend application built using **React 19**, **Redux Toolkit**, and **Tailwind CSS**.  
The app allows users to signup/login (localStorage based), search hotels via Amadeus API, paginate results, and compare selected hotels with charts.

---

##  Features

### Authentication (Local Storage Based)
- Signup & Login functionality
- User data stored in localStorage
- Protected routes using React Router

---

###  Hotel Search (Amadeus API)
- Search hotels by city
- Date range & guest input
- Load More pagination
- Hotel cards UI

---

### Compare Hotels
- Select multiple hotels
- Comparison page with charts (Recharts)
- Price & rating visualization

---

### 🛠 Tech Stack
- React 19 + Hooks
- Redux Toolkit
- React Router v6
- Tailwind CSS
- Recharts
- Axios
- LocalStorage
